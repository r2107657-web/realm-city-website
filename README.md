# REALM CITY — دليل التشغيل الكامل

هذا الدليل يوديك خطوة بخطوة من "ملفات على جهازك" إلى "موقع حقيقي بيه رابط، ومربوط بسيرفرك".

⚠️ **مهم:** ما أقدر أرفع لك الموقع بنفسي ولا أدخل على سيرفرك مباشرة (ما عندي وصول لأي شبكة أو بيانات دخول). لكن هذا الدليل مكتوب بحيث تسويه بنفسك بـ15-20 دقيقة بدون أي خبرة برمجة سابقة.

---

## الخطوة 1 — إنشاء حساب Railway (الاستضافة)

1. روح لـ **https://railway.app** وسجّل حساب مجاني (فيه خيار تسجيل عن طريق GitHub، وهذا أسهل).
2. لو ما عندك حساب GitHub، سوّي وحد مجاني من **https://github.com** أول (بس بريد إلكتروني وكلمة مرور).

## الخطوة 2 — رفع ملفات المشروع على GitHub

1. من موقع github.com، اضغط **New repository**.
2. سمّه مثلًا `realm-city-website` واختر **Private** (خاص) واضغط **Create repository**.
3. بصفحة المستودع الفاضي، اضغط **uploading an existing file**.
4. اسحب عليها **كل الملفات والمجلدات** اللي بعطيك إياها (بما فيها مجلد `public` ومجلد `resources` وملف `server.js` و`package.json`).
5. اضغط **Commit changes**.

## الخطوة 3 — إنشاء المشروع على Railway

1. رجعلك لـ railway.app، اضغط **New Project**.
2. اختر **Deploy from GitHub repo** وحدد المستودع اللي رفعته `realm-city-website`.
3. Railway بيكتشف إنه مشروع Node.js تلقائيًا ويبدأ يجهزه.

## الخطوة 4 — إضافة قاعدة البيانات (MySQL)

1. بنفس المشروع على Railway، اضغط **+ New**.
2. اختر **Database → Add MySQL**.
3. بعد ما تنشئ، روح لتبويب **Variables** بخدمة الـMySQL وشوف القيم:
   `MYSQLHOST`, `MYSQLPORT`, `MYSQLUSER`, `MYSQLPASSWORD`, `MYSQLDATABASE`.

## الخطوة 5 — ربط قاعدة البيانات بالموقع

1. روح لخدمة الموقع (مو خدمة الـMySQL) بنفس المشروع → تبويب **Variables**.
2. ضيف المتغيرات هذي (خذ القيم من خدمة الـMySQL اللي شفتها بالخطوة الفوق):

```
DB_HOST=<قيمة MYSQLHOST>
DB_PORT=<قيمة MYSQLPORT>
DB_USER=<قيمة MYSQLUSER>
DB_PASS=<قيمة MYSQLPASSWORD>
DB_NAME=<قيمة MYSQLDATABASE>
DISCORD_WEBHOOK_URL=<رابط الويب هوك من قناتك بالديسكورد>
```

> **كيف تسوي رابط الويب هوك؟** بالديسكورد: إعدادات القناة → Integrations → Webhooks → New Webhook → Copy Webhook URL.

3. احفظ. Railway بيعيد تشغيل الموقع تلقائيًا بالمتغيرات الجديدة.

## الخطوة 6 — تفعيل رابط عام (Public URL)

1. بخدمة الموقع، روح تبويب **Settings → Networking**.
2. اضغط **Generate Domain**.
3. بيطلع لك رابط زي: `realm-city-website-production.up.railway.app`

🎉 هذا هو رابط موقعك الحقيقي! افتحه بمتصفح كروم وجرّب تقدّم طلب — بيوصلك إشعار بالديسكورد فورًا.

---

## الخطوة 7 — ربط السيرفر (txAdmin / FXServer) بالتفعيل التلقائي

عشان اللاعب يدخل السيرفر تلقائيًا بس يتفعّل من الموقع:

1. تأكد إن عندك مورد **oxmysql** مثبت بسيرفرك (أغلب سيرفرات الفايف فايف عندها أصلًا). إذا ما عندك، حمّله من:
   `https://github.com/overextended/oxmysql`
2. اربط oxmysql بنفس قاعدة بيانات Railway اللي سويتها (نفس بيانات `DB_HOST`, `DB_USER`... فوق) — تحطها بملف `.cfg` تبع oxmysql حسب تعليماته.
3. انسخ مجلد `resources/realm_whitelist` (اللي جهزته لك) لمجلد `resources` تبع سيرفرك (عن طريق FTP أو لوحة txAdmin → File Manager إذا متوفرة).
4. افتح ملف `resources/realm_whitelist/config.lua` وبدّل الرابط بـ `Config.KickMessage` لرابط موقعك الحقيقي (من الخطوة 6).
5. من txAdmin: روح **Resources** → دوّر على `realm_whitelist` → اضغط **Start** (أو ضيف سطر `ensure realm_whitelist` بملف `server.cfg` تبعك وأعد تشغيل السيرفر).

من هذي اللحظة: أي لاعب يحاول يدخل، السيرفر يتحقق تلقائيًا من معرف الديسكورد تبعه بقاعدة البيانات — إذا مفعّل يدخل عادي، إذا لا ينطرد برسالة توجهه للموقع.

---

## الخطوة 8 — ربط دفع حقيقي (اختياري، لاحقًا)

حاليًا أي طلب يتفعّل فورًا بدون دفع فعلي. لما تحدد بوابة الدفع اللي بتستخدمها (Tap / MyFatoorah / PayPal)، تعال قولي واربطها لك بحيث التفعيل ما يصير إلا بعد تأكيد الدفع الفعلي (فيه مكان جاهز لها بملف `server.js` بالـ`/api/payment-webhook`).

---

## ملخص الملفات

| الملف / المجلد | وظيفته |
|---|---|
| `public/index.html` | الواجهة الأمامية للموقع |
| `server.js` | السيرفر الخلفي (يستقبل الطلبات، يخزن بقاعدة البيانات، يرسل ديسكورد) |
| `resources/realm_whitelist/` | مورد الـFiveM اللي يتحقق من التفعيل عند دخول اللاعب |
| `.env.example` | نموذج للمتغيرات (تحطها فعليًا بـ Railway مو بملف محلي) |

أي خطوة تعلّقت فيها، قولي وين وصلت بالضبط وأساعدك كملها.
